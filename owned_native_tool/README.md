# Owned native object workflow

This optional, separately coded fixture imports no tosem02 encoder or decoder.
It uses the same WMR2 experimental record specification, including its key tag,
XOR stream and truncated payload checksum. Existing crypto/provenance mechanisms
are not removed or promoted to a secure watermark construction. It is not an
independently maintained production product or a novel encoding.

The interface is embed -> LLVM object emission -> section-bound extraction ->
actual object loading/execution. On the measured Windows llvmlite runtime,
`jitdefault` emits ELF64 ET_REL despite the Windows default triple; the calling
convention is native Windows AMD64. A COFF preflight failed and is retained
privately. This does not execute an ELF Linux process or standalone executable.

Install the optional `requirements.txt` into an isolated runtime directory and
add that directory plus `artifact/` and `artifact/src/` to PYTHONPATH. On Windows
use semicolons. The original dependency-free test discovery does not include
`owned_native_tests`. The runtime is not bundled in this artifact; its licenses
remain with its official wheel. No global install or remote service is needed.

From artifact/ with the measured optional dependency:

```text
python -B owned_native_tool/tool.py embed --family affine --variant 0 --payload-hex 4d6f7270682d3031 --key key-alpha --profile IR0-backend0 --out NEW_DIRECTORY
python -B owned_native_tool/tool.py extract --artifact NEW_DIRECTORY/artifact.obj --key key-alpha
python -B owned_native_tool/tool.py run-owned --directory NEW_DIRECTORY --inputs 0 1 5 13 144 99991
python -B -m unittest discover -s owned_native_tests -v
python -B evaluation/run_owned_native.py --small --out NEW_SMALL_DIRECTORY
python -B evaluation/run_owned_native.py --out NEW_FULL_DIRECTORY
python -B evaluation/run_owned_native.py --replay --out results/owned-native-full-20261014-001
```

Fresh activities refuse existing directories. Saved replay actually recompiles
and reloads owned objects and compares all non-timing record fields; it writes
no candidate result. The run-owned receipt binds locally generated bytes, not
author identity or arbitrary-object safety. Execute only owned generated
arithmetic objects; this is not a machine-code sandbox or external target tool.

The full fixed activity crosses four host families, four variants and two
profiles, ten clean relation shapes and twelve integrity controls per context:
320 clean + 384 controls = 704 rows. It emits 832 objects and performs 5760
native calls. All emitted objects execute the six frozen host inputs; 768 of
the calls also supply explicit semantic/relocation relations. Outcomes are
352 satisfied, 32 inconsistent and 320 inadmissible. The separate small
activity has 44 rows, 52 objects and 360 native calls. Replays are not additional
independent samples.

Integrity controls are checksum-only, no-op, payload-only, payload/checksum,
outside-checksum material, and restoration before extraction, each with normal
and checksum-bypass decoding. Only checksum-only is an admitted intervention:
32 normal controls satisfy and 32 bypass controls are inconsistent; each other
mode has 64 inadmissible full-cohort rows. The same-information ordinary direct
byte-mask/endpoint checker agrees on 416 integrity rows. The locality-only
ablation is derived from the same observations, not a rerun of the old Linux
code or the Causal Testing Framework. Its 64 restoration attributions illustrate
missing identity evidence, not newly discovered production defects.

Full initial activity wall time is 3.2835572 s; summed case wall/process CPU is
3.2010323/3.171875 s, median/maximum wall case 0.0038619/0.0518251 s. Case costs
include compiler/object generation, actual object execution, file I/O, all
observations, direct projection and complete temporary-case cleanup. Activity
also includes gzip writing and aggregation. Dependency installation and process
startup are excluded. The receipt field `compile_write_seconds` includes the
per-build native/reference check; it is not a compilation-only measurement.
Direct projection costs exclude shared acquisition and are not a free baseline.
Object-byte sums and receipt sizes are experiment artifacts, not deployment,
runtime memory, physical database/WAL or total lifecycle benefits.

Raw rows contain source IR, emitted object hex, inputs/native outputs, build
profiles, extraction observations, admission facts and captured identities.
Intervened object bytes are reconstructible from the saved source object and
fixed mode; they are not stored as a second complete object dump. Replays
reconstruct and observe those actual follow-ups. This is not a complete OS,
filesystem or compiler-internal trajectory receipt.

Only the whole-artifact string-record admission projection is reused by this
native adapter. Its independent decoder's authority is the .wmrec section.
There is exactly one valid owned record in the generated artifact. The new
activity does not execute the original three-carrier Linux support envelope,
GCC/Clang diversity, MR12 concurrency, or unseen historical defects. Core MR10
still shares its parser family; the separate native decoder is finite evidence,
not a parser proof. See `PROOFS.md` and `SOURCES.md`.
