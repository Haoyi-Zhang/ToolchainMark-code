# External-transfer runner path defect

A release-candidate verification on 2026-07-25 invoked the packaged external-transfer runner against the six fixed public source files. The runner referred to an earlier compatibility-header filename while the packaged file had been renamed. Native-mode rows remained executable, but every compatibility-mode compile failed before the relation oracle ran. The failure is classified as a re-execution-harness defect, not as evidence about the external example pairs.

The previously frozen successful result set is retained under `frozen-results-before-repair/`. A sanitized account of the failed packaged attempt is in `failed_packaged_rerun_summary.json`. The runner now resolves the actual packaged header, asserts its presence, normalizes external source paths, and the complete 120-row study plus 12 sanitizer cases was regenerated. The regenerated case summary, relation verdicts, sanitizer rows, and summary are byte-identical to the previous successful evidence. Across all 120 execution rows, all 13 predeclared non-timing scientific fields are identical; only timing and normalized diagnostic text are outside that comparison. Only the regenerated result directory contributes to manuscript estimands.
