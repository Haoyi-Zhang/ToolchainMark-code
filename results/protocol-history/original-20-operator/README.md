# Preserved original 20-operator protocol

This directory retains the frozen evidence that preceded the relation-semantics audit. It is not pooled with the final 24-operator protocol. The original final design exposed all 60 carrier-operator units, but the later audit found that sequential payload separation and nominal parallel isolation used the same effective action order, and that reordered extraction did not observe the intervening artifact. The source snapshots, raw matrices, summaries, and same-protocol comparison are retained so the protocol change is auditable.
